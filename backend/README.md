# Backend Mechanics

As instruções de execução, variáveis de ambiente, autenticação e documentação Swagger estão no [README principal](../README.md).

Para iniciar somente a API localmente, configure `DATABASE_URL`, `DATABASE_USERNAME`, `DATABASE_PASSWORD` e `JWT_SECRET`, e execute `./mvnw.cmd spring-boot:run` nesta pasta. A interface Swagger é servida em `/swagger-ui.html`.
